# 鄭公館｜Codex 互動 3D

公開的住宅即時 3D 導覽，使用 Three.js 與 Draco 壓縮模型。

- WASD／方向鍵移動、拖曳轉向、手機搖桿。
- 牆體及家具碰撞、六房間快速定位、小地圖。
- 點選新增家具查看來源，切換日夜及室內照明。
- 圖集提供 Cycles 效果圖與固定視點全景。

GitHub Pages：從 main 分支根目錄部署。首頁會開啟互動漫遊。

## 範圍

網頁模型為減面與壓縮版本；不包含完整 Blender 原檔。屬視覺提案，產品型號、實際尺寸、採購與施工尚需確認。櫃門及家電為靜態；即時光照不同於離線寫實渲染。
